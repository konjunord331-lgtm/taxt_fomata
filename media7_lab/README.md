# MEDIA7 LAB

Place ce dossier directement dans la racine du repo `taxt_fomata`, au même niveau que `src/` et `composer.json`.

Structure attendue :

```text
taxt_fomata/
├── src/
├── composer.json
└── media7_lab/
    ├── index.php
    ├── start.bat
    └── README.md
```

Sous Windows, double-clique sur `start.bat`. Le labo ouvre ensuite `http://127.0.0.1:8080/`.

Prérequis : PHP 8.1+ disponible dans le PATH Windows.
